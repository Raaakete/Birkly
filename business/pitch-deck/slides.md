## Slide 2 — Problem

**CMS forces a bad trade-off**

- SaaS CMS → fast start, **vendor lock-in** and rising seats/API bills
- WordPress → familiar, but **complexity & security** debt
- Headless stacks → powerful, but **npm/ops overhead**

**Notes:** One story: “Teams want control without becoming sysadmins.”

---

## Slide 3 — Solution

**Birkly: self-hosted content platform**

- Upload PHP — **no database, no npm** in core
- Admin + API for editors **and** developers
- Portable flat files — **Git-friendly, migratable**
- Extensions via **curated marketplace**

**Notes:** Contrast with “another SaaS” in first 30 seconds.
