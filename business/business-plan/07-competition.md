# 07 — Competition

## Competitive landscape

| Competitor | Strengths | Weaknesses vs Birkly |
|------------|-----------|----------------------|
| **WordPress** | Ecosystem scale, familiarity | Legacy complexity, security expectations, database + plugin conflict risk |
| **Strapi** | Modern admin, API-first | Node/npm stack, hosting overhead |
| **Contentful / Sanity / Storyblok** | Polished SaaS DX, collaboration | Recurring cost, vendor lock-in, data off-prem |
| **Directus** | Open source, SQL-backed | Database dependency, heavier ops |
| **Statamic / Kirby** | Flat-file, PHP/Laravel quality | Smaller ecosystems; Kirby is proprietary licensed |
| **Ghost** | Publishing focus | Narrower scope (blog/newsletter) |

## Birkly differentiation matrix

| Dimension | Birkly |
|-----------|--------|
| **Runtime dependencies** | Zero npm/composer in **core** |
| **Database** | Not required (flat files) |
| **Hosting** | Standard PHP shared hosting |
| **Extension model** | Auto-discovered plugins + curated marketplace |
| **Visual builder** | Studio (in-CMS IDE + production builder) |
| **Commerce** | First-party Commerce plugin + payments integration |
| **AI** | Structured content + approval workflows, MCP hooks |
| **Business model** | Open core + marketplace (not content SaaS rent) |
| **UI architecture** | Admin templates decoupled from API/core |

## Honest weaknesses (pre-beta)

- **Brand awareness:** zero compared to WordPress or Contentful.
- **Ecosystem size:** marketplace catalog early — chicken-and-egg vs WordPress plugins.
- **Enterprise features:** SSO, advanced audit, multi-tenant SaaS not primary focus yet.
- **Team scale:** **[TBD]** — capacity vs incumbents with large engineering orgs.

## Positioning statement

> For developers and agencies who need **portable, self-hosted content infrastructure** without SaaS lock-in or Node build chains, Birkly is a **flat-file CMS platform** with an integrated marketplace and visual builder — unlike headless SaaS, you own the files; unlike WordPress, you start with a modern API-first architecture and minimal runtime surface.

## Competitive response strategy

1. **Niche depth first** — agencies + EU sovereignty + AI-ready structured content.
2. **Marketplace quality over quantity** — QC pipeline as trust signal.
3. **Studio as moat** — visual builder tied to Birkly templating, not generic page builders.
4. **Values consistency** — no bait-and-switch to mandatory cloud.
