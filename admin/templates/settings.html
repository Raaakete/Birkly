API Information

The HaruCMS API allows external applications and domains to access your content programmatically. This page provides information about API endpoints and configuration.

API Endpoint

The API is available at: /api/

Authentication

API requests require proper authentication via session cookies or API keys. See the Domains tab to register domains for API access.

Rate Limiting

API requests are rate-limited per domain to prevent abuse. Rate limits can be configured in the Domains tab.

API Documentation

For detailed API documentation, including available endpoints, request/response formats, and authentication methods, please refer to the HaruCMS documentation or contact your system administrator.
