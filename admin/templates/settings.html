Claude, ChatGPT, and Cursor reject http:// connector URLs. Open Birkly using https:// on a public address, then copy the Connector URL shown here. HTTP and localhost URLs will not work in Claude.

Quick start

  1. Click Add agent and give your AI agent a name and role.
  2. Copy that agent's unique Connector URL (not the site-wide /mcp path).
  3. In Claude, ChatGPT, or Cursor: paste the URL only — leave Client ID and Client Secret empty.
  4. Test with a read-only question, e.g. "List my Birkly collections".
