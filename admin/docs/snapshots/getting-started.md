# Getting started with Birkly

Welcome to Birkly — a flat-file CMS with a visual admin panel. This guide covers your first steps after setup.

## After onboarding

1. **Explore the dashboard** — See recent activity and quick links.
2. **Open Content** — Browse collections and create your first entry.
3. **Check Settings** — Set your project name, branding, and security options.
4. **Read the docs** — Use Help in the sidebar or the search on this page.

## Key concepts

- **Collections** group related entries (e.g. blog posts, products).
- **Entries** are individual content items with fields defined by the collection schema.
- **Templates** on your website pull data from collections via the Birkly client library.
