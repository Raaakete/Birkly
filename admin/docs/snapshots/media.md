# Media library

Upload and manage images and files used in entries and templates.

## Uploading

- Drag and drop files onto the media page or use **Upload**.
- Supported types depend on server configuration.

## Using media

- Pick files in entry fields (media/image field types).
- Reference URLs in templates via the client library.

## Organization

- Search and filter by name or type.
- Delete unused files to save space (check entries first).
