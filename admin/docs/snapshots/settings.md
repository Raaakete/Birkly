# Settings

Configure your Birkly installation from **Settings** in the sidebar.

## Tabs

| Tab | Purpose |
|-----|---------|
| **General** | Project name, timezone, language |
| **Users & roles** | Invite users, assign roles |
| **Plugins** | Enable/disable extensions |
| **Security** | Session timeout, 2FA options |
| **API** | Public API keys and endpoints |
| **Domains** | Allowed domains for client library |
| **AI Connections** | BYOAI providers, models, approval rules |

## Alpha feedback

Admins can review tester feedback under **Alpha Feedback** in the sidebar.
