# Plugins

Plugins extend Birkly with extra admin pages, field types, APIs, and integrations.

## Managing plugins

1. Open **Settings → Plugins**.
2. **Enable** plugins you need; configure API keys if required.
3. **Disable** when no longer needed.

## What plugins can add

- Sidebar navigation items
- Custom field types
- Automation triggers and actions
- External integrations (Slack, email, CRM)

## Safety

Plugins run with CMS-level access. Only use trusted sources and keep them updated.

## Bundled examples

- **automation** — workflow builder
- **user_management** — site user registration/login
