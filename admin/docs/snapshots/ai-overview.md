# AI assistant

Birkly includes a built-in AI assistant accessible from any admin page via the floating AI button.

## Setup

1. Go to **Settings → AI Connections**.
2. Add a provider (OpenAI, Anthropic, Ollama, OpenRouter, etc.).
3. Set the model, role (permissions), and whether write actions need approval.

## Using the chat

- Click the floating AI button (bottom-right).
- Ask questions about your collections, entries, or CMS features.
- The AI can read data and, with permission, propose write actions.

## Approvals

When **require approval** is enabled, write actions appear in an approval queue before they execute.

## Security

Each connection has a role that maps to CMS permissions. Use the least privilege needed.
