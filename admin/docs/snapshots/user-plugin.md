# User management plugin

The **user_management** plugin adds front-end registration, login, and member areas to your site.

## Enabling

1. **Settings → Plugins** — enable User Management.
2. Configure registration, email, and password rules in plugin settings.
3. Add the plugin's field types to collections as needed (e.g. Password field).

## Features

- User registration and login forms for your website.
- Role mapping between site users and CMS permissions (where configured).
- Password strength validation and secure storage.

## Security

Only install from trusted sources. The plugin can access user data and authentication flows.
