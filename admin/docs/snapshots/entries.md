# Entries & collections

Collections define the structure of your content. Each collection has a schema (fields) and contains entries.

## Collections

- Create collections in **Content → New collection**.
- Add fields: text, rich text (ContentEditor), media, dates, and more.
- Set slugs, statuses (draft/published), and permissions per collection.

## Entries

- Create entries from a collection's entry list.
- Use the **entry editor** to fill in fields and save or publish.
- Sub-entries allow nested content (e.g. comments on a post).

## Status workflow

Typical flow: **Draft** → **Review** → **Published**. Your role determines which transitions you can perform.
