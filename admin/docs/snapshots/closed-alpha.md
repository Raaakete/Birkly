# Closed alpha guide

Birkly is in **closed alpha**. This phase focuses on BYOAI, automation, user plugin, feedback, and ContentEditor blocks.

## What to test

- Connect your own AI provider (OpenAI, Anthropic, Ollama, etc.)
- Assign a role and keep **require approval** enabled for write actions
- Use the floating AI chat button for read actions (list collections, entries)
- Approve or reject pending writes in Settings → AI Connections → Approval queue
- Try MCP with a per-connection API key (`mcp-bridge.js`)
- Enable the Automation plugin and create a simple entry-trigger workflow
- Register a site user via the User Management plugin (if enabled)
- Submit alpha feedback via the floating feedback button
- Search Help for AI, automation, or ContentEditor topics

## Feedback data

In-app feedback may include your message, page context, and account email. See Birkly-Website legal pages for retention and privacy practices.

## Reporting issues

Use the in-app feedback widget or note the daily agent digest in `docs/agent-ops/daily-reports/`.
