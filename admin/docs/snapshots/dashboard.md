# Dashboard

The dashboard is your admin home. It shows an overview of your CMS and quick actions.

## What you see

- **Activity feed** — Recent changes across collections, media, and users.
- **Onboarding checklist** — For new installs, steps to complete initial setup.
- **Quick links** — Jump to Content, Media, Settings, or Help.

## Tips

- Use the global search (**Ctrl+K** / **Cmd+K**) from any page to find entries and collections.
- The floating **AI** button opens the assistant; the **feedback** button lets you report alpha issues.
