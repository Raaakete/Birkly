# Entry editor

The entry editor is where you create and update individual content items.

## Layout

- **Breadcrumbs** — Navigate back to the collection or content list.
- **Action bar** — Save, publish, or change status.
- **Fields** — Rendered from the collection schema (text, ContentEditor, media, etc.).

## Saving

- **Save** keeps changes without necessarily publishing.
- **Publish** (when available) makes the entry visible on your site according to collection rules.

## ContentEditor fields

Rich text fields use the ContentEditor fieldtype — stored as pure HTML with optional block components.

## Tips

- Use the **?** help link next to the page title for contextual documentation.
- Unsaved changes may be lost if you navigate away — save frequently.
