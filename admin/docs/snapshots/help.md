# Help & documentation

Birkly Help connects the admin panel to product documentation (Birkly-Docs).

## Search

Use the search box on this page to find topics by title or keyword. Results link to in-admin snapshots synced from Birkly-Docs.

## Contextual help

Look for the **?** icon next to page titles (dashboard, entry editor, settings). It opens the relevant help topic.

## Full documentation

For the complete, up-to-date docs, visit docs.birkly.com (Birkly-Docs).
