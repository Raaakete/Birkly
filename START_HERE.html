How will you run Birkly?

On your computer

Run locally with PHP — best for learning and development.

On a web server

Upload to your host via FTP or file manager for a live site.

1

Open a terminal in your Birkly folder

You need a terminal pointed at the folder that contains admin/, start-server.sh, and this file.

How to open a terminal here (Windows, Mac, Linux)

Mac: Open Finder → go to your Birkly folder → right-click → New Terminal at Folder (or drag the folder onto Terminal).

Windows: Open the Birkly folder in File Explorer → click the address bar → type cmd and press Enter. Or use Windows Terminal / PowerShell and cd to the folder.

Linux: Open your file manager → right-click the Birkly folder → Open in Terminal, or run cd /path/to/Birkly.

2

Start the Birkly server

Run these commands in that terminal. Keep the window open while you work.

First time only (Mac/Linux) — make the script executable:

chmod +x ./start-server.sh

Start on the default port (8080):

./start-server.sh

Optional — custom port or stop an old server first:

# Kill anything on the port, then start on 8001
./start-server.sh -k -p 8001
Or use XAMPP, MAMP, Laragon, etc.

Point your stack's document root at this Birkly folder (the one with admin/ and index.php). Use your stack's URL instead of localhost:8080 in the steps below.

3

Open this page through the server

Do not continue from a file:// tab. Open Birkly in your browser at:

http://localhost:8080/START_HERE.html

After the server is running, click below or paste the URL into your browser.

PHP not installed yet?

Birkly needs PHP 8.0+. Install options:

Mac: brew install php

Windows: php.net or XAMPP.

Linux: sudo apt install php

1

Upload all files

Upload everything in this folder to your web root. Keep the structure — admin/, api/, and core/ must stay siblings.

FTP / file manager tips (FileZilla, Cyberduck, cPanel)
  • Upload the full folder, not only admin/
  • Typical web root: public_html, www, or htdocs
  • After upload, visit https://yourdomain.com/START_HERE.html to verify
2

Permissions & PHP

Make these folders writable by the web server: content/, media/, users/, settings/, logs/.

PHP 8.0+ required. Apache installs can use the included .htaccess for routing.
