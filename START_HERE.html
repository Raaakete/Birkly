Let's get started

Choose how you want to run Birkly. We'll guide you through setup and then open the admin wizard.

How to unzip Birkly (Windows, Mac, Linux) ▼

Windows: Right-click the zip → Extract All… → choose a folder like Documents\Birkly. Open the extracted folder — you should see admin, api, and START_HERE.html together.

Mac: Double-click the zip. If you get Birkly/Birkly/ (double-nested), move the inner folder up one level.

Linux: unzip Birkly-*.zip -d ~/Birkly

More help: Birkly getting-started docs

PHP not installed — how to install ▼

Mac: brew install php

Windows: Download from php.net or use XAMPP.

Linux: sudo apt install php

2

Start the server

In the Birkly folder, run:

chmod +x ./start-server.sh
./start-server.sh

Keep the terminal open. Default URL: http://localhost:8080

Upload everything in this folder to your web root via FTP or your host's file manager. Keep the folder structure intact.

FTP upload tips ▼
  • Use FileZilla, Cyberduck, or your host's file manager
  • Upload admin/, api/, core/, and all root files
  • Do not upload only the admin folder — the CMS needs sibling folders
