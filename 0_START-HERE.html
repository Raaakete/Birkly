1. Check if PHP is installed

powershell -ExecutionPolicy Bypass -File .\check-php.ps1
./check-php.sh
./check-php.sh

Birkly needs PHP on your PC. If the check fails, run the installer below. It downloads PHP from the official Windows build and unpacks it into a runtime\php folder inside your Birkly folder — you do not unzip anything yourself or change Windows PATH.

powershell -ExecutionPolicy Bypass -File .\install-php.ps1

When it finishes, close PowerShell, open it again at the Birkly folder, and run the check command again.

Birkly needs PHP on your Mac. If the check fails, download PHP 8+ from php.net/downloads and install it. Close the terminal, open it again at the Birkly folder, and run the check once more.

Birkly needs PHP. If the check fails, download PHP 8+ from php.net/downloads and install it, then run the check again.

2. Start the PHP server

powershell -ExecutionPolicy Bypass -File .\start-server.ps1
./start-server.sh
./start-server.sh

Leave this window open while you use Birkly. If port 8080 is busy, use powershell -ExecutionPolicy Bypass -File .\start-server.ps1 -Port 8001 -Kill./start-server.sh -k -p 8001./start-server.sh -k -p 8001 (pick your own port instead of 8001).

Permission denied

Run the commands from inside your Birkly folder (not from inside the zip file). On Mac you can use chmod +x check-php.sh start-server.sh once, then ./check-php.sh and ./start-server.sh.

PHP not found or check failed

Install PHP from the official download links in step 1, then restart the terminal.

Optional on Mac: Laravel Herd or Homebrew brew install php.

Use install-php.ps1 first (step 1). Optional GUI installer: Laragon. On Windows 11 you may also try winget install PHP.PHP.8.3 if winget is available — then open a new terminal.

The one-liner on php.net often fails (wrong PHP version, security policy, or PATH). The Birkly installer script is the supported path.

Optional: your distro package manager (e.g. sudo apt install php php-mbstring php-curl).

Birkly needs PHP 8.0+ with json, mbstring, curl, and openssl.
