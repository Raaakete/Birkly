📋 Local Development Setup

1Check Requirements

Make sure you have PHP 7.4 or higher installed. Check by running:

php -v

The server script will automatically check this for you.

2Start the Server

Open a terminal/command prompt in this directory and run:

Option A - Using the provided script (recommended):

chmod +x ./start-server.sh
./start-server.sh -k

The -k flag will automatically kill any existing server on the port.

Option B - Using a specific port:

./start-server.sh -k -p 8001

Option C - Using PHP built-in server directly:

php -S localhost:8080 -t . server-router.php

Important: Always use server-router.php when running PHP server directly, or use the start-server.sh script (recommended) which handles this automatically.

The server will start on http://localhost:8080 (or the port you specified).

3Verify Server is Running

Check the server status above, or visit:

http://localhost:8080/test-server.php

This will verify that PHP is executing correctly and the router is working.

💡 Tip: If port 8080 is already in use, you can specify a different port: 
./start-server.sh -k -p 8001
Then update the URLs accordingly (e.g., http://localhost:8001/admin).

📋 Web Server Deployment

1Upload Files

Upload all HaruCMS files to your web server using FTP, SFTP, or your hosting provider's file manager.

Important: Upload all files and folders, including the admin/, api/, core/, and all other directories.

Make sure to preserve the directory structure.

2Configure Your Server

For Apache:

The included .htaccess file should work automatically. Make sure mod_rewrite is enabled.

For Nginx:

Use the provided nginx.conf.example as a reference. Key points:

server {
    listen 80;
    server_name yourdomain.com;
    root /path/to/harucms;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}

3Set Permissions

Make sure these directories are writable by the web server:

chmod -R 755 content/ media/ users/ settings/ logs/

On some shared hosting, you may need to set permissions via your hosting control panel.

4Verify Installation

Open your browser and navigate to:

https://yourdomain.com/test-server.php

Replace yourdomain.com with your actual domain name. This will verify that PHP is executing correctly.

💡 Tip: For shared hosting, most providers support PHP out of the box. Just upload the files and visit your domain's /admin path.
