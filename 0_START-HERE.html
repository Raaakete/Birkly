HaruCMS is a simple content management system that works without a database. Choose how you want to set it up below. Don't worry - we'll guide you through every step!

Perfect for testing and learning. We'll help you start a local server on your computer.

🌐 On a Web Server

For your live website. Upload the files to your web hosting provider.

📋 Setting Up on Your Computer

1Open Terminal

On Mac: Press Cmd + Space, type "Terminal", and press Enter.

On Windows: Press Windows + R, type "cmd", and press Enter.

On Linux: Press Ctrl + Alt + T.

2Navigate to This Folder

In the terminal, type this command (replace with your actual folder path):

cd /path/to/your/harucms/folder

Or simply drag the folder into the terminal window and it will fill in the path automatically.

3Start the Server

Copy and paste this command into your terminal and press Enter:

./start-server.sh

The script will check if PHP is installed and start the server automatically.

You should see a message saying "Starting server on http://localhost:8080". Keep this terminal window open!

4Check if Server is Running

Look at your terminal window. If you see "Starting server on http://localhost:8080", your server is running!

If you see an error message, the script will tell you what's wrong (like PHP not being installed).

Check Your Terminal

📋 Setting Up on a Web Server

1Upload All Files

Using your hosting provider's file manager or FTP program, upload all files and folders from this HaruCMS folder to your web server.

Make sure to keep the folder structure the same (don't change folder names).

2Visit Your Website

Open your web browser and go to:

https://yourdomain.com/admin

Replace yourdomain.com with your actual website address.

💡 Tip: Most hosting providers work automatically. If you see an error, contact your hosting provider's support - they can help you configure it.

✅ Ready to Continue?

If you can see the login page, you're ready to start the setup!

Replace "yourdomain.com" with your actual website address in the link below:

Start Setup →

Or visit: https://yourdomain.com/admin/index.php?page=onboarding
