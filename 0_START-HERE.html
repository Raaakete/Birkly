How are you running PHP locally?

1

Open a terminal in your Birkly folder

Open a terminal in the folder where you extracted Birkly — the complete project folder where this file sits alongside admin/ and start-server.sh.

How to open a terminal here (Windows, Mac, Linux)

Mac: Finder → your Birkly folder → right-click → Services → New Terminal at Folder. On newer macOS you may see New Terminal at Folder directly in the right-click menu.

Windows: Open the folder in File Explorer → click the address bar → type cmd → Enter. Or use Windows Terminal and cd to the folder.

Linux: Right-click the folder → Open in Terminal, or cd /path/to/Birkly.

Browsers cannot open a terminal for you — use one of the methods above.

2

Start the Birkly server

Run in the terminal and keep the window open:

./start-server.sh

Optional — custom port or stop an old server first:

./start-server.sh -k -p 8001
Permission denied on ./start-server.sh?

On Mac/Linux only, run once: chmod +x ./start-server.sh — then try ./start-server.sh again. Windows usually does not need this.

1

Point your PHP stack at this folder

Note the URL your stack gives you (e.g. http://localhost:8888) — use it in the steps below instead of localhost:8080.

Mac: brew install php

Upload all files

Upload everything in this folder to your web root. Keep the structure — admin/, api/, and core/ must stay siblings.

FTP / file manager tips (FileZilla, Cyberduck, cPanel)
  • Upload the full folder, not only admin/
