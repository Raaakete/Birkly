Stop — extract the zip first

You are viewing this page inside the zip file or without a running server. Birkly cannot work until the files are extracted to a normal folder.

  1. Close this browser tab.
  2. In File Explorer (the folder icon on your taskbar — not Chrome or Edge), find the Birkly zip you downloaded.
  3. Right-click the zip → Extract All… → choose Desktop or Documents → Extract.
  4. Open the new folder (same name as the zip, not the zip itself).
  5. Double-click 0_START-HERE.html in that folder (same file the invite email mentions).
Common mistakes:
  • Opening files inside the zip without Extract All (use Unblock on the zip in Properties if Windows warns you).
  • Typing cmd in the browser — use File Explorer and the .bat files instead.
  • Closing the blue security screen without choosing More info → Run anyway.

macOS says Birkly Launch cannot be opened?

Downloaded apps are often quarantined. Birkly Launch only runs PHP on your Mac (localhost) — it does not upload your project.

First time: Right-click Birkly Launch.app → Open → confirm Open again. Or use Birkly Launch.command (opens Terminal).

After the zip is extracted, the app must sit next to admin/ — not inside the zip file.

Windows says the file may be unsafe?

That is normal for downloaded software. Birkly is not signed with a Microsoft certificate yet. The .bat files only start PHP on your computer (localhost) — they do not send your files to us.

Before you extract the zip: In Downloads, right-click the Birkly .zip → Properties → if you see Unblock, tick it → Apply → then Extract All.

When you double-click Birkly Launch.exe or a .bat file: On the blue “Windows protected your PC” screen, click More info → Run anyway. Or right-click the file → Run.

Birkly is not code-signed yet — the same SmartScreen steps apply to the launcher and the .bat helpers.

Start the Birkly server

②

Double-click Birkly Launch.exe (opens your browser when the server is ready).

Advanced: use start-server.bat instead

Double-click start-server.bat. Same rules: leave the window open. Do not double-click start-server.sh on Windows.

②

Double-click Birkly Launch.app (Terminal opens with the server — leave it open).

Advanced: use ./start-server.sh in Terminal

Same rules: keep the Terminal window open while you use Birkly.

Run in the terminal and keep the window open:

./start-server.sh

./start-server.sh -k -p 8001
