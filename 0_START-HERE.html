👋 Let's Get Started

Birkly is a simple content management system that works without a database. Choose how you want to set it up below.

💻 On Your Computer

Perfect for testing and learning. We'll help you start a local server on your computer.

🌐 On a Web Server

For your live website. Upload the files to your web hosting provider.

1

Check if PHP is Installed

First, we need to check if PHP is installed on your computer. PHP is required for Birkly to run.

Open a terminal and run this command:

php -v

If you see version information (like "PHP 8.1.0"), PHP is installed! ✅

If you see an error (like "command not found"), PHP is not installed. ❌

PHP is not installed - How to install it ▼

On Mac:

Option 1: Using Homebrew (recommended)

brew install php

Option 2: Download from php.net

On Windows:

Option 1: Download from php.net

Option 2: Use XAMPP or WAMP (includes PHP)

On Linux:

sudo apt install php

Or for other distributions:

sudo yum install php
How to open a terminal ▼

On Mac:

  • Press Cmd + Space
  • Type "Terminal"
  • Press Enter

On Windows:

  • Press Windows + R
  • Type "cmd"
  • Press Enter

On Linux:

  • Press Ctrl + Alt + T
2

Start the Server

Now that PHP is installed, let's start the server. Open a terminal in the Birkly folder and run:

./start-server.sh

You should see a message saying "Starting server on http://localhost:8080". Keep this terminal window open!

How to open terminal in the project folder ▼

Method 1: Drag and Drop (Easiest)

  • Open Terminal
  • Type cd (with a space after "cd")
  • Drag the Birkly folder into the terminal window
  • Press Enter

Method 2: Navigate Manually

  • Open Terminal
  • Type cd followed by the path to your Birkly folder
  • For example: cd /Users/yourname/Documents/Birkly
  • Press Enter

Method 3: Right-click in Folder (Mac/Linux)

  • Right-click on the Birkly folder
  • Select "Open Terminal Here" or "Open in Terminal"
Port is already in use - What to do ▼

If you see an error about the port being in use, it means the server might already be running.

Solution 1: Check if the server is already running by opening http://localhost:8080/admin in your browser.

Solution 2: Kill the existing server and start a new one:

./start-server.sh -k

Solution 3: Use a different port:

./start-server.sh -p 8001

Then use http://localhost:8001 instead of http://localhost:8080

3

Check if Server is Running

Look at your terminal window. If you see "Starting server on http://localhost:8080", your server is running! ✅

If you see an error message, check the troubleshooting section below.

ℹ️

Check Your Terminal

Look at the terminal window where you ran the command. If it says "Starting server on http://localhost:8080", your server is running!

Troubleshooting - Server not starting ▼

Problem: "PHP is not installed"

Go back to Step 1 and install PHP first.

Problem: "Permission denied"

Make the script executable:

chmod +x ./start-server.sh

Then try again:

./start-server.sh

Problem: "Port already in use"

See the troubleshooting section in Step 2.

Problem: "Command not found" or script doesn't run

Make sure you're in the Birkly folder. Check with:

pwd

You should see the path to your Birkly folder.

Still having issues?

Make sure you're using the latest version of Birkly from GitHub. If problems persist, check the README.md file for more help.

1

Upload All Files

Using your hosting provider's file manager or FTP program, upload all files and folders from this Birkly folder to your web server.

Make sure to keep the folder structure the same (don't change folder names).

How to upload files using FTP ▼

Using an FTP Client (FileZilla, Cyberduck, etc.):

  • Download and install an FTP client
  • Connect to your web server using your hosting credentials
  • Upload all files and folders from the Birkly folder
  • Make sure to preserve the folder structure

Using Your Hosting Provider's File Manager:

  • Log into your hosting control panel (cPanel, Plesk, etc.)
  • Open the File Manager
  • Upload all files and folders from the Birkly folder
  • Extract any ZIP files if needed
2

Set File Permissions

Some folders need to be writable by the web server. Set permissions for these folders:

chmod -R 755 content/ media/ users/ settings/ logs/

On most shared hosting providers, this is done automatically. If you see permission errors, contact your hosting provider's support.

How to set permissions via hosting control panel ▼

Using cPanel File Manager:

  • Right-click on each folder (content, media, users, settings, logs)
  • Select "Change Permissions"
  • Set to 755 (or 777 if 755 doesn't work)
  • Check "Recurse into subdirectories"

Using SSH/Terminal:

chmod -R 755 content/ media/ users/ settings/ logs/

Note: If you're not sure how to do this, contact your hosting provider's support. They can help you set the correct permissions.

3

Visit Your Website

Open your web browser and go to:

https://yourdomain.com/admin

Replace yourdomain.com with your actual website address.

If you see the login page, everything is working! ✅

Troubleshooting - Can't access admin panel ▼

Problem: "404 Not Found" or "Page not found"

Make sure all files were uploaded correctly. Check that the admin/ folder exists on your server.

Problem: "500 Internal Server Error"

This usually means PHP isn't working or there's a permission issue. Contact your hosting provider's support.

Problem: "Permission denied"

Go back to Step 2 and set the correct permissions for the folders.

Problem: Blank page or PHP errors

Make sure your hosting provider supports PHP 7.4 or higher. Contact support if you're not sure.

Still having issues?

Contact your hosting provider's support. They can help you configure the server correctly.
