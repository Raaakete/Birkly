🚀 Welcome to HaruCMS

Your flat-file, zero-dependency CMS is ready to go!

👋 First Steps

HaruCMS is a flat-file CMS that works without a database. Choose your setup path below to get started. Once your server is running, you'll be guided through the onboarding process to set up your site.

💻 Local Development

Perfect for testing, development, or running on your own computer.

🌐 Web Server

Deploy to a live web server (Apache, Nginx, or shared hosting).

📋 Local Development Setup

1Check Requirements

Make sure you have PHP 7.4 or higher installed. Check by running:

php -v

2Start the Server

Open a terminal/command prompt in this directory and run one of these options:

Option A - Using the provided script (recommended):

chmod +x ./start-server.sh
./start-server.sh

Option B - Using PHP built-in server directly (not recommended):

php -S localhost:8080 -t . server-router.php

Important: Always use server-router.php when running PHP server directly, or use the start-server.sh script (recommended) which handles this automatically.

The server will start on http://localhost:8080 (or the port you specified).

3Access the Admin Panel

Open your browser and navigate to:

http://localhost:8080/admin
💡 Tip: If port 8001 is already in use, you can specify a different port: 
./start-server.sh -p 8080
or 
php -S localhost:8080

✅ Server Running?

Once you see the admin login page, you're ready to continue!

Go to Admin Panel →

📋 Web Server Deployment

1Upload Files

Upload all HaruCMS files to your web server using FTP, SFTP, or your hosting provider's file manager.

Important: Upload all files and folders, including the admin/, api/, core/, and all other directories.

2Configure Your Server

For Apache:

The included .htaccess file should work automatically. Make sure mod_rewrite is enabled.

For Nginx:

Use the provided nginx.conf.example as a reference. Key points:

server {
    listen 80;
    server_name yourdomain.com;
    root /path/to/harucms;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}

3Set Permissions

Make sure these directories are writable by the web server:

chmod -R 755 content/ media/ users/ settings/ logs/

On some shared hosting, you may need to set permissions via your hosting control panel.

4Access the Admin Panel

Open your browser and navigate to:

https://yourdomain.com/admin

Replace yourdomain.com with your actual domain name.

💡 Tip: For shared hosting, most providers support PHP out of the box. Just upload the files and visit your domain's /admin path.
