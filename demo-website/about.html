About HaruCMS

HaruCMS is designed for simplicity and flexibility. Unlike traditional database-driven CMS platforms, HaruCMS uses simple JSON files to store your content, making it:

  • Fast: No database queries, just file reads
  • Portable: Move your entire site by copying a folder
  • Version-controlled: Every change is tracked in your version control system
  • Secure: No SQL injection vulnerabilities
  • Flexible: Edit content directly in your code editor if needed

This Demo Website

This demo website showcases how easy it is to create a professional website with HaruCMS. The entire website uses minimal JavaScript—just one script tag to connect to the CMS. All content is fetched dynamically from the CMS and rendered using HaruCMS's simple templating language.
