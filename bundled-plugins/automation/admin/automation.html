Slack / Teams / Webhooks

There is no separate Slack login in Setup. For each workflow action, paste an Incoming Webhook URL from Slack or Teams (or any HTTPS webhook endpoint). Outbound HTTP uses PHP curl (see checklist above).

  1. In Slack: Apps → Incoming Webhooks → Add to channel → copy URL.
  2. In your automation, add a Slack (or Webhook) action and paste the URL.
  3. Save, then Confirm & Run Live (Test will not post).

Optional: keep the queue draining with cron

Entry create/update already tries to process a few jobs immediately. Cron is still useful for backlog, schedules, and reliability if the admin request is interrupted. 

* * * * * php plugins/automation/cli/process_queue.php 10
