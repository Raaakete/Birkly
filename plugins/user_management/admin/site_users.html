What is the User Management Plugin?

The User Management Plugin is a comprehensive system for managing users, authentication, profiles, and permissions in your Birkly website. It provides everything you need to:

  • Create and manage user accounts - Add, edit, delete, and organize users
  • Handle user authentication - Login, logout, password reset, email verification
  • Manage user profiles - Custom profile fields, profile collections, user relationships
  • Control access - Permissions, roles, tiers, and collection-level access control
  • Organize users - Groups, tiers, and user relationships (connections, followers, following)

Who is this for? This plugin is designed for website administrators who need to manage users, whether for a simple blog with comments, a membership site, a social network, or any website that requires user accounts.

🚀 Getting Started

Step 1: Configure Basic Settings

Start by going to the General tab and configuring your registration settings:

  1. Allow public registration - Enable this if you want users to be able to sign up themselves. Disable it if you only want admins to create accounts.
  2. Require email verification - When enabled, users must verify their email before their account is activated.
  3. Require admin approval - When enabled, new users must be approved by an admin before they can log in.
  4. Auto-approve new users - Automatically approve users after they verify their email (if email verification is enabled).

Step 2: Create Your First User

Go to the User List tab and click "Add User" to create your first user account:

  • Enter the user's name and email
  • Set a password (or leave blank to send a password reset email)
  • Choose a role (Member, Subscriber, Premium, or VIP)
  • Set the status (Active, Inactive, or Pending)

Step 3: Set Up Profile Fields (Optional)

In the General tab, scroll to "Profile Fields" to add custom fields to user profiles:

  • Click "Add Field" to create a new profile field
  • Choose a field type (text, email, phone, date, etc.)
  • Set whether the field is required
  • Add help text to guide users
💡 Tip: Start simple! You can always add more profile fields, groups, and tiers later as your needs grow.

👥 Managing Users

User List Tab

The User List tab is your main workspace for managing users. Here you can:

Search and Filter

  • Search - Type in the search box to find users by name, email, or ID
  • Filter by Role - Show only users with a specific role
  • Filter by Status - Show only active, inactive, or pending users
  • Filter by Tier - Show only users in a specific tier

User Actions

  • Add User - Click the "Add User" button to create a new account
  • Edit User - Click on a user's name or email to edit their account
  • Delete User - Click the delete button (trash icon) to remove a user (soft delete)
  • Reset Password - In the user edit modal, click "Reset Password" to send a password reset email
  • Export Users - Click "Export CSV" to download a list of all users

User Statuses

  • Active - User can log in and use the site normally
  • Inactive - User account is disabled, cannot log in
  • Pending - User account is waiting for approval or email verification

User Roles

  • Member - Basic user role, default for new users
  • Subscriber - For users with subscription access
  • Premium - For premium members
  • VIP - For VIP members with highest access

Note: Roles are primarily for organization. Actual permissions are controlled through Tiers and Collection Permissions.

⚙️ Settings Explained

Registration Settings

Allow public registration
When enabled, anyone can create an account through your registration page. When disabled, only admins can create accounts.
Require email verification
Users must click a link in their email to verify their email address before their account is activated.
Require admin approval
New users must be manually approved by an admin before they can log in. You'll see pending users in the User List.
Auto-approve new users
Automatically approve users after they complete email verification (if enabled). Otherwise, they remain pending until manually approved.

Profile Collection Settings

Profile collections allow you to store user profiles as entries in a collection, enabling advanced features like social connections, custom fields, and more.

Enable collection profiles
When enabled, user profiles are stored as entries in a collection. This enables features like user relationships (connections, followers, following).
Profile collection
Select which collection to use for storing profiles. You can create a new collection or use an existing one.
Auto-create profiles
Automatically create a profile entry when a new user is created. If disabled, profiles must be created manually.
Migrate user profiles
Click this button to create profile entries for all existing users who don't have one yet.

Default Settings

Default role
The role assigned to new users when they register.
Default tier
The tier assigned to new users. Tiers control access to collections and features.

👤 Profile System

The plugin supports two types of profiles:

1. Plugin-Managed Profiles

Basic profile information stored directly in the user account. You can add custom fields in the General tab under "Profile Fields".

  • Simple and lightweight
  • Good for basic user information
  • Fields are managed in the plugin settings

2. Collection Profiles (Advanced)

Profiles stored as entries in a collection. This enables advanced features like:

  • User relationships - Connections, followers, following (using the User fieldtype)
  • Custom fields - Any field type available in collections
  • Media fields - Profile pictures, avatars, etc.
  • Rich content - Bio, descriptions, portfolios, etc.

Setting Up Collection Profiles

  1. Go to General tab → "Profile Collection Settings"
  2. Enable "Enable collection profiles"
  3. Select or create a collection for profiles
  4. Enable "Auto-create profiles" if you want profiles created automatically
  5. Click "Migrate user profiles" to create profiles for existing users

Profile Fields

In the General tab, you can add custom profile fields:

  • Field Name - Internal identifier (lowercase, underscores only, e.g., "phone_number")
  • Field Label - Display name shown to users (e.g., "Phone Number")
  • Field Type - Choose from text, email, phone, URL, number, date, textarea, select, radio, checkbox, or file
  • Required - Whether users must fill this field
  • Placeholder - Hint text shown in the input field
  • Help Text - Additional instructions for users

🔒 Permissions & Access Control

Tiers

Tiers control what features and collections users can access. Think of them as membership levels.

  • All - Default tier, basic access
  • Custom Tiers - Create tiers like "Premium", "Enterprise", etc.

To create a tier:

  1. Go to the Tiers tab
  2. Click "Add Tier"
  3. Enter a name and ID (lowercase, underscores only)
  4. Add features (optional) - These are feature names that other plugins can check for

Collection Permissions

Control which tiers can create, edit, and delete entries in each collection.

  1. Go to the Collection Permissions tab
  2. Click "Add Collection"
  3. Select a collection
  4. For each tier, check the permissions:
    • View - Can see entries
    • Create - Can create new entries
    • Edit - Can edit entries (their own or all, depending on settings)
    • Delete - Can delete entries (their own or all)
  5. Click "Save Permissions"
⚠️ Important: By default, if no permissions are set for a collection, all users can access it. Set permissions to restrict access.

🔗 User Fieldtypes

The plugin provides two special fieldtypes for use in collections:

1. User Fieldtype

Allows you to link entries to users or select users in collection fields.

Use cases:

  • Post authors (single user)
  • Team members (multiple users)
  • User connections, followers, following (multiple users)
  • Assigned to, created by, etc.

How to use:

  1. When editing a collection schema, add a field with type "user"
  2. Choose "Allow Multiple Users" if you want to select multiple users
  3. Optionally filter by roles (e.g., only show VIP users)
  4. In the admin, you'll see a user picker with search functionality

2. Password Fieldtype

Secure password field that encrypts passwords and provides password reset functionality.

Features:

  • Passwords are encrypted (admins cannot see them)
  • Password strength indicator
  • "Send Password Reset Email" button for existing passwords
  • Configurable minimum length and strength requirements

Use cases:

  • Profile collections that auto-create user accounts
  • Any collection where you need secure password storage

📝 Template Functions

The plugin provides template functions you can use in your website templates:

User Functions

{user_logged_in}
Returns true if a user is logged in, false otherwise. Use with {if user_logged_in}...{endif}
{user_current}
Returns the current logged-in user object with properties like id, name, email, role, etc.
{user_by_id "user_id"}
Get user information by user ID. Example: {user_by_id "user_123"}
{user_list}
Get a list of all active users. Returns an array you can loop through.

Profile Functions

{user_profile} or {user_profile "user_id"}
Get the profile entry for the current user or a specific user ID. Returns null if profile collection is not enabled or profile doesn't exist.
{user_is_self "user_id"}
Check if a user ID matches the current logged-in user. Returns true/false.

Relationship Functions

{user_in_field field_value}
Check if the current user is in a user fieldtype field value. Useful for checking connections, followers, etc.

Example Usage

{if user_logged_in}
    Welcome, {user_current.name}!
    {if user_profile exist}
        Your bio: {user_profile.bio}
    {endif}
{else}
    Please log in.
{endif}

💡 Common Use Cases

1. Simple Blog with Comments

  1. Enable public registration (optional)
  2. Create a "Comments" collection
  3. Add a "user" fieldtype field for the comment author
  4. Set collection permissions so "All" tier can create comments

2. Membership Site

  1. Create tiers: "Free", "Premium", "VIP"
  2. Set up collection permissions for each tier
  3. Assign users to appropriate tiers
  4. Use template functions to show/hide content based on tier

3. Social Network

  1. Enable collection profiles
  2. Create a profile collection with user fieldtypes for connections, followers, following
  3. Create a posts collection with visibility settings
  4. Use template functions to filter posts by relationships

4. Team Collaboration

  1. Create groups for different teams
  2. Add users to groups
  3. Use groups in collection permissions
  4. Create collections for projects, tasks, etc.

🔧 Troubleshooting

Users Can't Log In

  • Check user status - must be "Active"
  • Check if email verification is required - user may need to verify email first
  • Check if admin approval is required - user may be pending approval
  • Try resetting the password

Profile Collection Not Working

  • Make sure "Enable collection profiles" is checked
  • Verify the profile collection exists and is selected
  • Click "Migrate user profiles" to create profiles for existing users
  • Check that the collection has the required fields (user_id, name, email)

Permissions Not Working

  • Check that collection permissions are set in the Permissions tab
  • Verify the user's tier has the required permissions
  • Check that the user's status is "Active"
  • Remember: if no permissions are set, all users can access (by default)

Template Functions Not Working

  • Make sure the plugin is active
  • Check that you're using the correct function name and syntax
  • Verify user is logged in (for functions that require authentication)
  • Check browser console for JavaScript errors

Password Reset Emails Not Sending

  • Check your email configuration in Birkly settings
  • Verify SMTP settings are correct
  • Check spam folder
  • Make sure the user's email is correct
