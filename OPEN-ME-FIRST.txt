BIRKLY - READ THIS FIRST (Windows)
==================================

WINDOWS "UNSAFE FILE" WARNING (normal for downloads)
----------------------------------------------------
Birkly is not Microsoft-signed yet. Windows may warn you — you can still proceed.

BEFORE you extract the zip (recommended):
  1. Right-click the downloaded Birkly .zip file (in Downloads).
  2. Click Properties (bottom of the menu).
  3. On the General tab, if you see "Unblock" near the bottom, check it.
  4. Click Apply, then OK.
  5. Now use Extract All...

When you double-click check-php.bat or start-server.bat:
  - Blue screen "Windows protected your PC" → click More info → Run anyway.
  - Or right-click the .bat file → Run (not Open).

These files only start Birkly on YOUR computer (localhost). They do not install
hidden software. If your work PC blocks all scripts, ask IT or use Laragon.

Do NOT open files while they are still inside the zip.

1. Right-click the Birkly zip file you downloaded.
2. Choose "Extract All..." (or "Extract Here").
3. Open the NEW folder (not the zip).
4. Double-click:  0_START-HERE.html

Follow the steps in your browser.

No PHP yet?
  Double-click:  install-php-windows.bat
  Then:          check-php.bat
  Then:          start-server.bat  (keep that window open)
