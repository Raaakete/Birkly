📝 Legacy Templating Demo (Static Content)

This section shows the existing templating system working without routing:

Featured First, Newest First (with Index, Date, Filters)

{for each entry in 'blog' sort="first:featured:1, date:desc" limit=5}
{index}. {title|escape|default:Untitled}
{date|date:YYYY-MM-DD}
{content|escape}
{if featured}★ Featured{/if}
Author: {author}
{/for}

Only Featured Posts

{for each entry in 'blog' filter="featured=1" sort="date:desc"}
{title}
{date|date:YYYY-MM-DD}
{content}
{/for}

Non-Featured Posts (with If/Else)

{for each entry in 'blog' filter="featured=0" sort="date:desc" limit=3}
{title}
{if featured}★{else}Not Featured{/if}
{date|date:YYYY-MM-DD}
{/for}
