# Daily report — P6.4 Commerce closure (2026-07-04)

Phase 6.4 — **Commerce plugin** — is **complete** and ready to merge. Payments has been evolved into a content-first commerce platform at `plugins/commerce/`.

## What shipped

| Area | Detail |
|------|--------|
| **Migration** | `plugins/commerce/` replaces Payments; `plugins/payments/` is a compatibility shim |
| **Shelf** | `commerce_shelf` + `payment_shelf` alias — Shopping Cart and Events tests still pass |
| **Fieldtype** | `commerce` on fieldtype shelf — `price_cents`, `billing` (one_time/recurring), `quantity_available`, optional `sku` |
| **Catalog** | Indexer on entry save; admin Catalog tab |
| **Cart/Orders** | Session cart, checkout via shelf, quantity reservations, admin Orders |
| **Discounts** | Rule engine — coupons, affiliate `?ref=`, order line audit |
| **Import** | CSV + WooCommerce/Shopify presets |
| **Fulfillment** | Adapter interface + manual export + ShipStation stub |
| **Mappings** | Purchase → tier grant via UserTiers on paid order |

**Tests:** 83 PHP suites green.

## Deploy steps

1. `git pull origin main`
2. **Settings → Plugins** — activate **Commerce** (Payments shim auto-forwards if still active)
3. Settings/data migrate from `payments` → `commerce` on first bootstrap
4. Add **Commerce** fieldtype to collection schemas for purchasable entries
5. Hard-refresh admin

## Coexistence

- **Shopping Cart** and **Events** plugins remain — use legacy collections OR migrate entries to Commerce fieldtype over time
- New sites: use Commerce fieldtype on any collection; avoid separate `shop_products` unless using legacy Shop plugin

## Deferred

- Shop/Events migration wizards (P6.5+)
- Live Shopify/Woo API import
- Marketplace
