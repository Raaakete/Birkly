# Birkly daily — 2026-07-05

Phase 6.5 Commerce Wave is complete. The legacy P6.4 flat commerce schema has been replaced with the approved v2 content model: merchants configure `fulfillment` (ship, deliver, register, none) independently from `purchase_options[]` (one-time and recurring on the same sellable unit). Variant sub-entries in a `variants` sub-collection are indexed as sellable SKUs; checkout snapshots the selected purchase option and routes post-purchase through a new `PostPurchaseRouter` (physical fulfillment, digital download tokens, event registration, membership triggers). Plugin docs shelf (`register_plugin_docs`) is live — Admin Help now shows a **Plugin extensions** section with Commerce as the first consumer, and Birkly-Docs publishes the v2 guides.

All four scenario acceptance fixtures pass in CI: yoga class (register + capacity), coffee (variants + dual purchase options + shipping), course (deliver + download token), and community (none + recurring + tier mapping). Regression suites for `payment_shelf` alias, Shopping Cart, and Events remain green. **89 test suites PASS** on `main`.
