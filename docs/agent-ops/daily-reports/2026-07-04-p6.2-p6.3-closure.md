# Daily report — P6.2 + P6.3 closure (2026-07-04)

Phase 6.2 (Shopping Cart) and Phase 6.3 (Events) are **complete** and merged to `main`. Both plugins consume `payment_shelf` only — no direct provider API calls.

## What shipped

| Plugin | Path | Highlights |
|--------|------|------------|
| **Shopping Cart** | `plugins/shopping_cart/` | `shop_products` collection seed, session cart API, checkout → shelf, orders admin, `order_*` automation triggers |
| **Events** | `plugins/events/` | `events` collection seed, free RSVP (no Payments), paid tickets via shelf, capacity, registrations admin, `event_*` automation triggers |

**Tests:** 74 PHP suites green (`shopping_cart_*`, `events_*` shelf consumer tests included).

**Docs:** Birkly-Docs `shopping-cart-plugin.md`, `events-plugin.md`; shelf API cross-links updated.

## How to try on live site

1. `git pull origin main` on the server.
2. **Settings → Plugins** — activate **Payments** (if not already), then **Shopping Cart** and **Events**.
3. **Shop** — view orders after test checkout; products in Content → `shop_products`.
4. **Events** — free RSVP via API; paid tickets need a Payments connection.

Hard-refresh admin after pull.
