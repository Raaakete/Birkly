Forms

Modular Form Input Blocks

  • Use {add entry to 'collection'}...{/add} to define custom forms.
  • Fieldtype helpers: {input name="field"}, {select name="field"}, etc.
  • Value binding: {{ field }} for pre-filled values.
{add entry to 'feedback'}
  {input name="name"}
  {textarea name="message"}
  {input name="email"}
  <button type="submit">Send Feedback</button>
{/add}

HaruForm JS Helper

  • Attach to any form for AJAX submission, CSRF, and error handling.
  • Hooks: onSuccess, onError.
<script>
new HaruForm('myFormId', {
  onSuccess: data => { /* show success */ },
  onError: err => { /* show error */ }
});
</script>

Anti-Spam & Security

  • Honeypot field (hidden input)
  • Simple math CAPTCHA (if enabled)
  • Akismet integration (if configured)
  • Rate limiting and CSRF protection are enforced automatically

File Uploads

  • Use {media name="attachment"} or <input type="file" ...> for file fields.
  • Files are validated and stored securely.

Email Notifications

  • Set notify_email in collection config to receive emails on new submissions.

Best Practices

  • Keep forms simple and user-friendly.
  • Use anti-spam features for public forms.
  • Validate and sanitize all input.
