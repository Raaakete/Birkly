Users

User Roles & Permissions

  • Roles: Admin, Editor, Author, Viewer
  • Each role has specific permissions for content, media, users, settings, and plugins.

Authentication

  • Session-based authentication for admin API and UI.
  • Secure password hashing and session cookies (Secure, HttpOnly, SameSite).

User Management

  • Add, edit, and delete users via the admin UI (/admin/users.html).
  • Assign roles and manage user details.

Session Security

  • Session timeout and auto-logout are enforced.
  • Sessions are destroyed on logout or timeout.

Best Practices

  • Use strong, unique passwords for all users.
  • Limit admin access to trusted users only.
  • Regularly review user roles and permissions.
