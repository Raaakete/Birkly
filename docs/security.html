Security

Security Architecture

  • Strict input validation and output escaping
  • CSRF protection for all state-changing actions
  • XSS protection (backend and frontend)
  • File upload security (type, size, content, storage)
  • Session security (Secure, HttpOnly, SameSite cookies, timeout, auto-logout)
  • Role-based access control
  • Rate limiting on sensitive/public endpoints
  • Security logging for critical actions
  • Anti-spam: honeypot, CAPTCHA, Akismet

Security Review Checklist

  • CSRF Protection
  • XSS Protection
  • File Upload Security
  • Rate Limiting
  • Session Security
  • Access Control
  • Security Logging
  • General Input Validation

Best Practices

  • Keep HaruCMS and all dependencies up to date
  • Use strong, unique passwords for all users
  • Review logs and permissions regularly
  • Enable all available security features
  • Limit public form submissions and use anti-spam

Actionable Recommendations

  • Enable rate limiting and security logging on all endpoints
  • Configure allowed file types and size limits
  • Set up email notifications for critical actions
  • Regularly back up your data and test restores
