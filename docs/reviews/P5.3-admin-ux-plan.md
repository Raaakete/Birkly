# P5.3 — Admin UX & core workflows

**Status:** Approved (2026-06-16, Keven)  
**Follows:** Phase 5 + P5.1 + P5.2 complete on `main`  
**Trigger:** Live kekaba testing (`birkly.kekaba.com`) — entry drill-down broken, automation dead, dashboard stuck on onboarding, feedback 404, DnD broken, FAB clutter, general admin UX debt

---

## Problem summary

| # | Symptom | Root cause (investigated) |
|---|---------|---------------------------|
| 1 | Entry list opens but clicking an entry does nothing / 404 | P5.2-M3 fixed `entries.html` links; **entry-detail**, **smart-table**, **entry-editor**, **collection-editor** still hardcode `/admin/index.php` — breaks on subdirectory embed (`/Birkly-0.1/admin/...`) |
| 2 | Sub-collections / sub-entries navigation broken | Same hardcoded URLs in `entry-detail.html`; sub-entry query params (`sub_collection`, `sub_entry`) not preserved in all links |
| 3 | Automation stuck on "Loading automations…"; Create does nothing | **JS parse error:** duplicate `let automations` in `plugins/automation/admin/automation.js` lines 5–6 — entire script fails to load |
| 4 | Automation API may fail on subdirectory install | `fetch('/api/automation.php')` — root-absolute paths, not `Birkly.url()` |
| 5 | Dashboard always shows onboarding checklist | `$showOnboarding = $wizardDone && !$fullyComplete` — skip/completion sets `setup_wizard_completed` but not `completed`; checklist items 4–6 hardcoded `false`; main sections gated behind `!$showOnboarding` |
| 6 | Alpha Feedback page "Page not found" | `getPageData()` in `api/admin_templates.php` has no `case 'feedback'` → returns error before template renders |
| 7 | Two floating buttons — different sizes, wrong AI icon, cluttered | Independent systems: `ai-chat-button.js` (56px, orange, layers icon) + `feedback-widget.php` (48px, blue, chat icon) — stacked with mismatched z-index and spacing |
| 8 | Can't drag collections between groups or reorder groups | `nested-drag-drop.js`: `addEventListener(..., true)` but `removeEventListener(..., false)` — listeners leak on re-render; `ungrouped` vs `''` groupId normalization edge cases in `content-groups.js` |
| 9 | Functional but poor UI/UX across admin | Inconsistent spacing, escaped `\"` in dashboard links, mixed URL helpers, layout regressions from rapid P4/P5 work |

---

## Goals

1. **Content workflows complete** — list → detail → edit for entries and sub-entries on subdirectory installs
2. **Automation usable** — page loads, list/create/edit works; API paths subdirectory-safe
3. **Dashboard useful after setup** — onboarding dismisses; stats + recent activity + collections visible
4. **Alpha feedback admin works** — triage page loads and lists submissions
5. **Elegant assist UI** — single unified FAB or compact action stack for AI chat + feedback
6. **Content organization works** — drag collections between groups; reorder groups
7. **UX baseline** — documented issue register + highest-impact layout fixes

**Out of scope:** Kekaba production deploy (deferred); full design system rewrite; dark mode; plugin marketplace

---

## Locked decisions (proposed)

| ID | Decision |
|----|----------|
| D1 | **Extend P5.2 D7** — all admin navigation URLs use `birkly_url()` / `admin_url()` / `{admin_url}`; zero hardcoded `/admin/index.php` in templates and JS redirects |
| D2 | **Onboarding gate:** after setup wizard, dashboard shows full content; checklist becomes collapsible banner or auto-hides when `completed` **or** `skipped` **or** all required checklist items done |
| D3 | **Skip = complete** for dashboard purposes — `onboarding skip` sets `completed: true` (or dashboard treats `skipped` as complete) |
| D4 | **Checklist truth** — derive media/settings/template completion from real state (media dir count, settings touched, templates exist) |
| D5 | **Unified FAB** — one bottom-right control: primary AI chat; secondary feedback via menu/tab — consistent 48px stack, shared z-index layer |
| D6 | **DnD fix** — match capture flags on add/remove listeners; normalize `ungrouped` / `''` in all drag callbacks |
| D7 | **Sub-entry URLs** — preserve `sub_collection` + `sub_entry` in breadcrumb, edit, and return links |
| D8 | Kekaba embed sync **deferred** — document deploy checklist; human triggers sync after P5.3 CMS merge |

## Technical approach

### Entry drill-down (P5.3-M0)

- `admin/templates/components/smart-table.php`: replace `buildEntryUrl()` hardcoded paths with `birkly_admin_url()`
- `admin/templates/entry-detail.html`: all links → `admin_url()` / `birkly_admin_url()`
- `admin/templates/entry-editor.html`, `collection-editor.html`: cancel/breadcrumb links
- `admin/js/entry-editor.js`: redirect URLs use `Birkly.url()` / `Birkly.adminUrl()`
- `admin/js/content-groups.js`: collection edit links
- Verify `getEntryDetailData()` handles sub-collection and sub-entry query params
- Tests: `admin_routing_http_test.php` — entry-detail, entry-editor with subdirectory base path

### Automation (P5.3-M1)

- Remove duplicate `let automations` line
- Replace `/api/automation.php` fetches with `Birkly.url('/api/automation.php')` or shared API helper
- Smoke: list loads, create modal opens, save round-trip

### Dashboard (P5.3-M2)

- `api/onboarding.php` skip action: also set `completed: true`
- `admin/templates/dashboard.html`: revise `$showOnboarding` — hide blocking welcome when skipped or checklist ≥ threshold
- `getDashboardData()`: real completion for media (count files in media dir), settings (non-default keys), templates (templates dir)
- Fix stray `\"` in `admin_url()` href attributes
- Ensure recent collections / activity / analytics sections render when onboarding dismissed

### Alpha feedback (P5.3-M3)

- Add `case 'feedback': return getFeedbackData();` to `getPageData()`
- Implement `getFeedbackData()` — CSRF token, empty list default (page JS loads via `api/feedback.php`)
- Verify sidebar nav + `feedback.html` + `feedback.js` load

### Drag and drop (P5.3-M4)

- `nested-drag-drop.js`: use matching capture flag (`true`) on removeEventListener; call `destroy()` before re-init in `content-groups.js`
- Audit `onCollectionMove` / `onGroupReorder` — consistent `ungrouped` id
- Manual smoke: move collection between groups; reorder two groups

### Unified FAB (P5.3-M5)

- **design-reviewer** proposes single FAB pattern (speed-dial or tabbed panel)
- Merge `feedback-floating-btn` into AI chat FAB stack or shared `admin/partials/assist-fab.php`
- One CSS module; consistent size, shadow, iconography (sparkle/bot for AI, flag/message for feedback)
- Remove duplicate z-index competition

### UX audit (P5.3-M6)

- Scan admin templates for hardcoded paths, broken hrefs, layout overflow
- Fix top 10 issues from live repro (issue register in `docs/reviews/p5.3-ux-issue-register.md`)
- design-reviewer pass on dashboard, content, entries, settings spacing
