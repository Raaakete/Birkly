## Problem statement

### Small issues (high visibility, quick wins)

1. **Content DnD** — Users cannot reorder collections inside a group or move cards between groups (e.g. Ungrouped ↔ Testgroup). Root cause cluster: `ungrouped` vs empty `groupId`, empty-group drop targets, collapsed groups, full re-render on save.

2. **Topbar chrome** — Search / notifications / account sit on an opaque white strip; should **blend with page background (transparent)**. Account bubble shows raw initials without circular badge styling → looks broken/clipped.

3. **AI knowledge gap** — Connected AI (Claude via MCP) knows sub-collection **template syntax** but not **admin operations**: creating sub-collections, nested entries, URL params, API paths, storage layout. Matches user screenshot: AI lists “what docs do NOT tell me.”

### Larger projects

4. **Onboarding** — First-run experience should feel modern and trustworthy. AI setup must be **optional**, not blocking. Flow needs audit: welcome → site info → demo content → dashboard checklist → optional AI connect.

5. **Automation plugin** — Needs visual polish, clearer builder UX, richer triggers (incl. sub-entries), and “easy first workflow” path for non-technical users.

---

## Vision

**P5.6** makes the admin shell feel finished: content organization works drag-and-drop, header looks intentional, AI assistants can guide real admin tasks, new sites onboard smoothly (with or without AI), and automation feels like a product feature—not a developer tool.
