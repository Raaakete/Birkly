## HTML output contract

```html
<!-- Table -->
<table class="content-editor-table" style="width:100%">
  <colgroup><col style="width:33%"></colgroup>
  <tbody>
    <tr>
      <td style="background:#f3f4f6;border-radius:8px;padding:12px">…</td>
    </tr>
  </tbody>
</table>

<!-- Grid -->
<div class="content-editor-grid" style="display:grid;grid-template-columns:repeat(auto-fit,minmax(200px,1fr));gap:16px">
  <div style="grid-column:span 2">…</div>
</div>
```

**Strip on save:** `data-ce-layout-id`, `data-ce-selected`, resize handles, inspector-only wrappers.

## Risks & mitigations

| Risk | Mitigation |
|------|------------|
| `commands.js` ~7k lines — layout adds debt | M4 extraction mandatory before closure |
| Admin `dropdown.js` class collision | CE menus stay under `.content-editor-toolbar`; add test note in M0 |
| Selection lost on modal open | Always `ContentEditorSelection.save()` before dialogs; restore before insert |
| Inline styles bloat HTML | Inspector uses shorthand; `processValue` normalizes empty styles |
