## OAuth endpoints (M3 reference)

Path-aware when Birkly runs in subdirectory (use `birkly_url()`):

```
GET  /.well-known/oauth-protected-resource[...]
GET  /.well-known/oauth-authorization-server[...]
GET  /oauth/authorize
POST /oauth/token
POST /oauth/register   (or registration_endpoint from discovery)
```

Unauthenticated MCP request must return:

```
HTTP/1.1 401 Unauthorized
WWW-Authenticate: Bearer resource_metadata="https://{host}/.well-known/oauth-protected-resource[...]"
```

See Anthropic claude-ai-mcp GitHub issues #269, #367, #402 for broker requirements.
