## Shelf API signature (implement in M0, finalize M3)

```php
interface PaymentShelfInterface {
    public function isConfigured(): bool;
    public function listProviders(): array;
    public function listAvailableProviders(array $context = []): array;
    public function resolveProvider(array $context): ?string;
    public function createPayment(array $request): array;
    public function capturePayment(string $ref): array;
    public function refundPayment(string $ref, ?int $amountCents = null): array;
    public function createSubscription(array $request): array;
    public function cancelSubscription(string $ref): array;
}
```
