## Post-deploy smoke (required)

### Built-in OpenAI assistant

1. **Settings → AI → Built-in assistant** → **Test connection** on your OpenAI row.
   - Expected: **Connection verified** (HTTP 200, not “Key accepted” on 404).
2. Open floating **AI Assistant** → ask: `which collections do I have?`
   - Expected: list of collections (no `OpenAI API error: 404`).
3. Optional: edit connection → set model to **gpt-4o-mini** explicitly.

### Claude MCP connector

1. **Settings → AI → Connect your AI app** → copy fresh **personal connector URL** (ends with `/mcp`).
2. In Claude: remove old connector → add new URL → sign in → approve consent.
3. Ask Claude to list collections and entries.
   - Expected: `list_collections` and `list_entries` succeed.
4. Request a write (e.g. create draft entry).
   - Expected: approval prompt appears **in Claude**, not in Birkly Approvals tab.

### Built-in chat approvals (outbound only)

1. Ensure outbound connection has **Require approval** enabled.
2. Ask built-in assistant to create content.
   - Expected: item appears in floating chat **Approvals** tab.
