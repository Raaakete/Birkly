## Path 3 — Claude remote connector (OAuth)

**Steps:** POST `/api/mcp_server.php` without credentials (simulates Claude broker probe).

**Pre-M3 local:**
```
HTTP/1.1 401 Unauthorized
Content-Type: application/json
(no WWW-Authenticate header)
```

**Expected by Claude broker:** RFC 9728 `WWW-Authenticate: Bearer resource_metadata="…"` → DCR → PKCE → bearer token.

**Live (`http://birkly.kekaba.com/Birkly-main/api/mcp_server.php`):** **404** — install not serving MCP (deployment gap).

**`/.well-known/oauth-protected-resource`:** **404** pre-M3; implemented in P4.1-M3.

**Verdict:** **FAIL** pre-M3 — root cause confirmed. **Fixed in M3** (`core/mcp_oauth.php`, `tests/mcp_oauth_test.php`).
