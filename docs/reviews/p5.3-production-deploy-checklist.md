# P5.3 production deploy checklist

**Target:** `birkly.kekaba.com` (`/Birkly-0.1/`)  
**Source:** Birkly `main` after PR #59 (P5.3)

## Deploy

1. Sync `main` PHP/JS/admin assets to production embed path
2. Do not overwrite runtime `users/`, `settings/`, `content/`, `media/`

## Smoke

1. **Entries:** Content → collection → click entry → detail → edit
2. **Sub-entries:** Open entry with sub-collections; navigate nested links
3. **Automation:** Plugins → Automation → list loads; Create opens builder
4. **Dashboard:** After onboarding skip, stats + recent activity visible
5. **Feedback:** Sidebar → Alpha Feedback page loads
6. **DnD:** Drag collection between groups; reorder groups
7. **FAB:** Single bottom-right button → AI chat + feedback options

## Troubleshooting

| Symptom | Check |
|---------|-------|
| Links still 404 | Hard refresh; confirm P5.3 deployed |
| Automation blank | Browser console for JS errors |
| Two FABs | Clear cache; unified CSS should hide old feedback FAB |
