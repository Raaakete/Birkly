# P5.4 — Deploy checklist (`birkly.kekaba.com`)

**After merging CMS PR to `main`:**

1. Sync kekaba embed: `./scripts/sync-client-embed.sh /path/to/kekaba`
2. Commit + push `kekaba` embed sync PR
3. Human deploys `kekaba/main` to production host
4. Hard refresh / clear CDN cache for `/Birkly-0.1/`
5. Run smoke on subdirectory install:

| Step | URL / action | Pass |
|------|----------------|------|
| Admin login | `/Birkly-0.1/admin/login.php` | |
| Content | `?page=content` — collections container, no pink error | |
| Entries | `?page=entries&collection={slug}` | |
| Entry detail | `?page=entry-detail&collection={slug}&entry={id}` | |
| Automation | `?page=automation` — list loads when plugin active | |
| Floating feedback | FAB visible on alpha installs; no sidebar triage | |
| AI | Ask templating conditional question in admin chat | |

**Platform owner install only:** set `settings/platform.json` → `"owner_mode": true` for Alpha Feedback triage sidebar.

**Alpha customer installs:** `"alpha_program": true`, optional `"feedback_relay_url"` + `"feedback_relay_secret"`.
