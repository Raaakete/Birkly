Deployment

Production Setup

  • Use Apache, Nginx, or PHP built-in server for production
  • Set correct permissions for /content, /media, /users
  • Disable directory listing and PHP execution in /media

Server Configuration

  • See nginx.conf.example and nginx.conf.sample for Nginx
  • Use .htaccess for Apache (sample provided)

Backups

  • Use the admin UI or /api/backup.php to create/restore backups
  • Store backups offsite for safety

Environment Variables

  • Configure via config.php or environment variables as needed

Troubleshooting

  • Check /logs/ for errors
  • Review permissions and server config
  • Consult the FAQ for common issues

Best Practices

  • Keep regular backups
  • Test restores before production changes
  • Monitor logs and server health
