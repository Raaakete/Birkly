# HaruCMS Ideas & Feature Inspirations

## Fieldtypes & Content Blocks
- Multi-item fieldtype (repeatable fields/groups)
- Maps/location fieldtype
- File upload & file manager fieldtype
- Block editor (modular content blocks)
- Gallery/image grid fieldtype
- Advanced relation fieldtype (with filters, display options)
- WYSIWYG/Markdown hybrid editor
- Table/structured data fieldtype
- Tag/label fieldtype
- Color picker
- Rating/star fieldtype
- Reference to external APIs (e.g. YouTube, Twitter embeds)

## UI/UX & Admin Experience
- Responsive, sortable, filterable, and searchable entry tables
- Draggable rows for manual ordering
- Customizable entry list columns (choose which fields to display)
- Full-screen editor modals
- Dashboard widgets (customizable overview)
- Collection cards show entry count
- Improved login and authentication flow
- Modern, clean, and accessible design
- Localization/Internationalization (multi-language support)

## Security & Permissions
- Plugin sandboxing and permission requests
- Admin user management with roles and permissions
- Invite team members/collaborators
- Two-factor authentication (2FA)
- Audit log for admin actions

## Integrations & Extensibility
- Plugin updating system
- CMS updating system
- Optional database backend (in addition to flat-file)
- Webhooks for content changes
- API access control per collection
- Third-party login/signup (Google, GitHub, etc)
- Integration with external forms (contact forms, etc)

## Publishing & Workflow
- Entry drafts and unpublished changes
- Scheduled publishing/unpublishing
- Content approval workflow (review, approve, publish)
- Version history and rollback

## Collaboration
- Real-time collaborative editing
- Commenting/notes on entries
- Activity feed for team actions

## Miscellaneous
- Custom dashboard/landing page
- Customizable themes/branding
- Accessibility improvements
- Performance monitoring tools
