Media

Uploading Files

  • Upload images, documents, and other files via the admin UI or API.
  • Allowed types and size limits are configurable in settings.

Media Library

  • All uploaded files are stored in /media/ and organized by folders.
  • Thumbnails are generated for images.
  • Metadata (filename, size, type, upload date) is stored for each file.

Security

  • Files are validated for type, extension, and content signature.
  • Malicious files and double extensions are blocked.
  • Files are stored with unique IDs and safe paths.

Using Media in Content

  • Use the Media field type in collections to attach files to entries.
  • In templates, render media using the field value (URL or ID):
    <img src="{{ entry.image }}" alt="...">

Best Practices

  • Keep file sizes reasonable for performance.
  • Use descriptive filenames and metadata.
  • Regularly review and clean up unused media.
