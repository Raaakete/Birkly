Templates

Output Templating

  • Loops: {% for entry in entries %}...{% endfor %}
  • Conditionals: {% if field %}...{% endif %}
  • Variables: {{ field }}
  • Filters: {{ field | date:YYYY-MM-DD }}
<ul>
{% for entry in entries %}
  <li>{{ entry.title }}</li>
{% endfor %}
</ul>

Modular Form Input Blocks

  • Use {add entry to 'collection'}...{/add} for public submissions.
  • Inside, use fieldtype helpers: {input name="title"}, {textarea name="message"}, etc.
  • Value binding: {{ field }} for pre-filled values.
{add entry to 'contact_form'}
  {input name="title"}
  {textarea name="message"}
  <button type="submit">Send</button>
{/add}

Best Practices

  • Keep templates simple and readable.
  • Use fieldtype helpers for consistency and validation.
  • Escape output where needed for security.
