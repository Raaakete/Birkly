HaruCMS Client Integration Guide

This guide shows how to integrate HaruCMS with your external website to display dynamic content.

1. Basic Setup

Include the HaruCMS script in your website:

<script src="https://your-harucms-domain.com/cms-template.v2.js"></script>

2. Static Content (Legacy Mode)

Use HaruCMS templating syntax directly in your HTML:

Example: Blog List

<div class="blog-posts">
  {for each entry in 'blog' sort="date:desc" limit=5}
    <article class="post">
      <h2>{title}</h2>
      <time>{date|date:YYYY-MM-DD}</time>
      <p>{content|escape}</p>
    </article>
  {/for}
</div>

3. Dynamic Routing (SPA Mode)

Enable dynamic routing for clean URLs by adding ?routing=true to your URL:

Example: Single Page Application

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>
    <nav>
        <a href="/">Home</a>
        <a href="/blog">Blog</a>
        <a href="/about">About</a>
    </nav>
    
    <main id="content">
        <!-- Content will be dynamically loaded here -->
    </main>
    
    <script src="https://your-harucms-domain.com/cms-template.v2.js"></script>
    <script>
        // Enable routing mode
        window.location.hash = '#routing';
    </script>
</body>
</html>

4. Available Routes

  • / - Home page with latest blog posts
  • /blog - Blog listing page
  • /blog/:slug - Individual blog post (e.g., /blog/my-awesome-post)
  • /page/:slug - Static pages (e.g., /page/about)

5. Templating Syntax

Loops

{for each entry in 'collection' sort="field:desc" filter="field=value" limit=10}
  <div>{title}</div>
{/for}

Conditionals

{if featured}
  <span>★ Featured</span>
{else}
  <span>Regular Post</span>
{/if}

Filters

{title|escape|default:Untitled}
{date|date:YYYY-MM-DD}
{content|escape}

Single Data Fetch

{from 'blog' get 'entry-id, title'}

6. JavaScript API

Access HaruCMS functions programmatically:

// Navigate to a page
window.HaruCMS.navigate('/blog/my-post');

// Get a specific entry
const entry = await window.HaruCMS.getEntryBySlug('blog', 'my-post-slug');

// Make API calls directly
const data = await window.HaruCMS.fetchAPI({
  action: 'list_entries',
  collection: 'blog'
});

7. Configuration

You can customize the API base URL by modifying the script or setting a global variable:

<script>
window.HARUCMS_API_BASE = 'https://your-harucms-domain.com/api/public.php';
</script>
<script src="https://your-harucms-domain.com/cms-template.v2.js"></script>

8. Example Integration

Complete Example Website

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
    <style>
        body { font-family: Arial, sans-serif; margin: 0; padding: 0; }
        nav { background: #333; padding: 1rem; }
        nav a { color: white; text-decoration: none; margin-right: 1rem; }
        .container { max-width: 800px; margin: 0 auto; padding: 2rem; }
        .post { margin-bottom: 2rem; padding-bottom: 1rem; border-bottom: 1px solid #eee; }
    </style>
</head>
<body>
    <nav>
        <a href="/">Home</a>
        <a href="/blog">Blog</a>
        <a href="/page/about">About</a>
    </nav>
    
    <div class="container">
        <!-- Static content example -->
        <h1>Latest Posts</h1>
        {for each entry in 'blog' sort="date:desc" limit=3}
            <div class="post">
                <h2><a href="/blog/{slug}">{title}</a></h2>
                <time>{date|date:YYYY-MM-DD}</time>
                <p>{content|escape}</p>
            </div>
        {/for}
    </div>
    
    <script src="https://your-harucms-domain.com/cms-template.v2.js"></script>
    <script>
        // Enable routing for dynamic navigation
        window.location.hash = '#routing';
    </script>
</body>
</html>

⚠️ Important Notes

  • Your HaruCMS server must be accessible from your website's domain
  • CORS must be properly configured on your HaruCMS server
  • The api/public.php endpoint must be publicly accessible
  • For production, consider using HTTPS for both your website and HaruCMS
