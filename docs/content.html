Content

Collections

Collections are groups of entries with a shared schema. Each collection has a collection.json config and a schema.json describing its fields.

Entries

Entries are content items within a collection. Each entry is stored as a JSON file in /content/collections/[collection]/entries/.

Schemas & Field Types

  • Text, Textarea, Number, Select, Checkbox, Date, DateTime, Media, Relation, Wysiwyg, etc.
  • Each field type has its own config and validation rules.

Relationships

Use the Relation field type to link entries across collections.

Versioning

Versioning is planned. For now, each entry is a single JSON file with created_at and updated_at timestamps.

Content API Basics

POST /api/content.php?action=list_entries&collection=blog
POST /api/content.php?action=get_entry&collection=blog&id=123
