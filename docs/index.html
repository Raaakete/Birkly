Welcome to HaruCMS Documentation

HaruCMS is a modern, flat-file, headless CMS designed for security, flexibility, and simplicity. This documentation covers all aspects of the system, from setup to advanced customization.

Advanced: JavaScript API

For developers who prefer custom JavaScript over the templating language, HaruCMS provides a direct JavaScript API. This allows you to:

  • Fetch content using the standard fetch() API
  • Integrate with React, Vue, Angular, or any JavaScript framework
  • Have full control over rendering and data manipulation
  • Submit forms using the Public Write API

See the Advanced JavaScript API section in the admin help panel for complete documentation with examples.
