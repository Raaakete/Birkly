Welcome to HaruCMS Documentation

HaruCMS is a modern, flat-file, headless CMS designed for security, flexibility, and simplicity. This documentation covers all aspects of the system, from setup to advanced customization.

Sections

  • Getting Started: Installation, requirements, and first steps
  • Content: Collections, entries, schemas, and versioning
  • Media: Uploads, library, and file security
  • Users: Roles, permissions, and authentication
  • Templates: Output and input templating, fieldtype helpers
  • Forms: Modular form input, public submissions, anti-spam
  • Security: Architecture, best practices, and review checklist
  • Extensibility: Plugins, custom field types, webhooks
  • API: Endpoints, usage, and examples
  • Deployment: Production setup, configuration, and backups
  • FAQ: Common questions and troubleshooting

Use the sidebar to navigate. Each section provides detailed explanations, code examples, and best practices.
