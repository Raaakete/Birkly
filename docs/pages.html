Pages

Overview

Pages in HaruCMS are static pages that provide the presentation layer for your website. They're different from content entries in that they define how your site is structured and displayed.

Page Types

  • Default Page: Standard static pages like About, Contact, etc.
  • Homepage: Your main landing page that can display content from other collections
  • Blog Listing: Pages that list blog entries or other content
  • Contact Page: Specialized pages with contact forms

Page Fields

  • Title: The page title (used in browser tab and SEO)
  • URL Slug: The URL path (e.g., "about" for /about)
  • Content: The main content of the page
  • Template: How the page should be displayed
  • Status: Published or Draft
  • Meta Description: SEO description
  • Featured Image: Main image for the page
  • Show in Menu: Include in navigation
  • Menu Order: Position in navigation menu

Creating Pages

  1. Go to Admin → Pages
  2. Click "Create Page"
  3. Fill in the required fields
  4. Choose a template based on your needs
  5. Set the status to "Published" to make it live

Page Templates

Homepage Template

The homepage template automatically displays your latest blog posts in a grid layout. Perfect for blogs and content-heavy sites.

Blog Listing Template

Shows a list of all blog entries with excerpts. Ideal for dedicated blog pages.

Default Template

Simple static page template for About, Contact, and other informational pages.

Navigation Menu

Pages with "Show in Menu" enabled will automatically appear in your site's navigation. Use "Menu Order" to control their position (lower numbers appear first).

URL Structure

Pages are accessible at the root level of your domain:

  • Homepage: /
  • About page: /about
  • Contact page: /contact
  • Blog listing: /blog

Best Practices

  • Use descriptive, URL-friendly slugs
  • Write compelling meta descriptions for SEO
  • Organize your navigation logically
  • Use appropriate templates for different page types
  • Keep drafts unpublished until ready

Integration with Content

Pages can display content from your collections. For example:

  • Homepage shows latest blog posts
  • Blog listing page shows all posts
  • Custom pages can use the templating system to display specific content
