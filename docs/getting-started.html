Getting Started

Requirements

  • PHP 8.1+ (recommended: 8.2+)
  • 100MB disk space (recommended: 1GB+)
  • 256MB RAM (recommended: 1GB+)
  • Modern web server (PHP built-in, Apache, Nginx, Valet, Herd, Docker, etc.)

Installation

  1. Clone or download the HaruCMS repository.
  2. Open a terminal in the project root.
  3. Start the PHP server:
    ./start-server.sh
    or manually:
    php -S localhost:8080 router.php
  4. Visit http://localhost:8080/admin/ in your browser.

Project Structure

/admin      # Admin UI (HTML, JS, CSS)
/api        # API endpoints (PHP)
/content    # Collections, entries, schemas
/fieldtypes # Field type modules
/media      # Uploaded files
/plugins    # Plugins
/templates  # Template files
/users      # User data

First Login

  • Default admin user is created on first run or see /users/ for user files.
  • Login at /admin/login.html with your credentials.
