Extensibility

Plugin System

  • Drop PHP files into /plugins/ to add functionality
  • Register hooks for events (e.g., after content save)
  • Sample plugin: 
    register_hook('after_content_save', function($collection, $entry) {
  // Custom logic here
});

Custom Field Types

  • Add new fieldtype folders to /fieldtypes/
  • Each fieldtype is self-contained (PHP, JS, CSS)
  • Register via FieldRegistry::register()

Events & Hooks

  • Core events: after_content_save, after_media_upload, etc.
  • Plugins can register for and trigger events

Webhooks

  • Planned: trigger external URLs on content changes, submissions, etc.

Best Practices

  • Keep plugins simple and secure
  • Document all custom field types and hooks
  • Test plugins in a safe environment before production

Roadmap

  • Plugin management UI
  • Advanced event system
  • Webhook configuration

Plugin Registration API

HaruCMS supports true drop-in plugins. Just copy your plugin folder into /plugins/ and it will be loaded automatically. Plugins can register collections, API endpoints, and admin pages at runtime.

Registering Features in plugin.php

// Register a collection (slug, path to collection folder)
register_collection('my_collection', __DIR__ . '/collections/my_collection');

// Register an API endpoint (route, path to handler)
register_api_endpoint('my_api', __DIR__ . '/api/my_api.php');

// Register an admin page (slug, path to HTML/JS or handler)
register_admin_page('my_admin', __DIR__ . '/admin/my_admin.html');

Accessing Plugin API Endpoints

Plugin API endpoints are accessible via the central API router:

POST /api/index.php?route=my_api

Best Practices

  • Always use register_collection, register_api_endpoint, and register_admin_page in your plugin.php to ensure your features are available at runtime.
  • Keep your plugin self-contained: all code, collections, and assets should be inside your plugin folder.
  • Document your plugin's features and configuration for users.
  • Test your plugin by simply copying it into /plugins/—no core changes required.
