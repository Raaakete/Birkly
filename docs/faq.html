FAQ

General

Q: What is Birkly?
A: A modern, flat-file, headless CMS for secure, flexible, and simple content management.

Q: What are the requirements?
A: PHP 8.1+, 100MB+ disk, 256MB+ RAM, modern web server.

Setup & Usage

Q: How do I install Birkly?
A: See Getting Started.

Q: How do I create a collection?
A: Use the admin UI or add a folder in /content/collections/ with collection.json and schema.json.

Q: How do I add users?
A: Use the admin UI or add a JSON file in /users/.

Security

Q: How is my data protected?
A: Birkly uses strong validation, CSRF/XSS/file upload protection, secure sessions, and access control.

Q: How do I enable rate limiting?
A: It is enabled by default on sensitive endpoints; see Security.

Extensibility

Q: How do I add plugins?
A: Drop PHP files into /plugins/ and register hooks.

Q: Can I add custom field types?
A: Yes, add a folder to /fieldtypes/ and register it.

Troubleshooting

Q: Where are errors logged?
A: See /logs/ for error and security logs.

Q: My server won't start or I get permission errors?
A: Check file/folder permissions and server config; see Deployment.

Best Practices

Q: How do I keep my site secure?
A: Keep Birkly updated, use strong passwords, enable all security features, and review logs regularly.
